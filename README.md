# Estudos PostgreSQL

Repositório feito com o intuito de estudar consultas SQL, em especial PostgreSQL, utilizando exercícios do beecrowd. Por enquanto foram feitos as seguintes atividades:

- [Customer Address](https://judge.beecrowd.com/en/problems/view/2603)
- [No Rental](https://judge.beecrowd.com/en/problems/view/2616)
- [Contest](https://judge.beecrowd.com/en/problems/view/2738)
- [Products by Categories](https://judge.beecrowd.com/en/problems/view/2609)
- [The Payback](https://judge.beecrowd.com/en/problems/view/2998)
- [Departments and Divisions](https://judge.beecrowd.com/en/problems/view/2989)
